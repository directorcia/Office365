Set up an experiment

Settings apply when you start or replay a world. Simulation speed, habitat clicks, and sprinkling work immediately.

Contact-born babies always inherit one parent's genes. When enabled, inherited genes can mutate and replacements inherit from a survivor; otherwise replacements have random genes.

Only starved bugs are replaced, not those killed by predators. No replacements are created if all bugs die in the same step.

Leave replacements off for a finite run that ends at extinction. Renewal settings apply only to renewable food; replay uses the same seed and settings.

Life over time

Points are sampled every 5 simulation seconds (the last sample may be shorter). Population shows the living count, births, starvation, and predation; generations shows average generation depth. The selection card reports changes from the first surviving sample.

01 / EXPLORE

A repeatable beginning

Leave starting counts blank for random amounts. A seed and the same settings recreate the same world.

02 / SURVIVE

Build up some health

Health starts at one food portion and drains continuously. Every blue food pill adds another full portion, so a well-fed bug can survive far longer. Bugs turn amber and red as their final portion runs low.

03 / BEGIN AGAIN

Life finds a way

Two green bugs need stored meals to produce a child that inherits one parent's movement genes. Enable mutation and inherited replacements to introduce variations and give replacements a survivor's genes. With replacement off, deaths reduce the population and finite worlds end when the last bug dies.

A simple simulation, not a scientific model.
